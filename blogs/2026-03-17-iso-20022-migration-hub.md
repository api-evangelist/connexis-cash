ISO 20022 Migration Hub joana.mendesge… Tue, 03/17/2026 - 13:51 What Is ISO 20022? ISO 20022 is the new global standard for financial messaging, replacing the legacy SWIFT MT format for all interbank cross-border and high-value payments and associated cash reporting. It uses XML-based messages (referred to as MX) which can carry richer, more structured, and more granular payment data than was possible with fixed-length MT messages.
